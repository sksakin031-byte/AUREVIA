# AUREVIA — fictional portfolio concept

A premium editorial website concept for a fictional interior design and architecture studio. The site is a portfolio demonstration, not a real business or service provider.

## Live website

- GitHub Pages: <https://sksakin031-byte.github.io/AUREVIA/>
- Manus-hosted version: <https://aurevia-hoajclxw.manus.space>

## Pages and source

The repository contains the static home, about, services, portfolio, six project case studies, contact, FAQ and custom 404 pages, with shared responsive CSS, JavaScript interactions, route metadata, `robots.txt`, `sitemap.xml` and an AUREVIA favicon.

The individual pages are generated by `tools/generate_site.py` from `tools/content.py` using only Python's standard library. From this repository root, regenerate the GitHub Pages files with:

```bash
python3 tools/generate_site.py --output .
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Illustrative content and assets

All six project concepts, locations, team identities and portraits are fictional. Architectural imagery is AI-generated conceptual visualization and is not presented as photography of completed client work. No real client reviews, credentials, service availability or business results are claimed. WebP images are served from the project's public Manus Storage URLs rather than duplicated as large repository binaries.

## Contact form

The contact enquiry is a browser-only demonstration with client-side validation. It has no submitting form element, backend or network endpoint; it does not send, email or store visitor entries. Contact details on the site are illustrative only.
