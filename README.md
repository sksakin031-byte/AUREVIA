# AUREVIA

Designed and developed a premium, fully responsive website for AUREVIA, a luxury interior design studio. Features modern UI/UX, elegant layouts, service pages, project galleries, interactive elements, and SEO-friendly structure for an exceptional user experience.

## Website source

This repository contains the complete static website source: the home, about, services, portfolio, FAQ, contact, and project-detail pages, plus shared CSS, JavaScript, route metadata, `robots.txt`, and `sitemap.xml`.

AUREVIA is a fictional portfolio/demo studio. Project names, reviews, figures, address, phone number, and email are illustrative placeholders.

## Run locally

From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Contact form

The contact form includes client-side validation, service selection, and budget selection. It is a demonstration only: it has no backend, does not send messages, and does not store form data.
